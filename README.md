# Web panel migration demo

Side-by-side recordings of the old Nuxt 3 panel (left) and the Next.js 16 +
shadcn/ui panel that replaces it (right), one per page. They are embedded in
the pull request that migrates `apps/web`; this branch only stores the files.

The data shown belongs to the wannacry_tm channel. The permissions and AI
system prompt pages are blurred because they hold data that is not channel
data.
